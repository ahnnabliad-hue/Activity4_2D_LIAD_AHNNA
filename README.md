Stacks and Queues: Array vs. Linked List

Description

This project demonstrates stack and queue implementations using arrays and linked lists.

Files

- "array_stack.py"
- "linked_stack.py"
- "array_queue.py"
- "linked_queue.py"
- "main.py"
- "analysis.md"
- "README.md"

Requirements

- Python 3
- Pydroid 3

How to Run

1. Save all Python files in the same folder.
2. Open "main.py" in Pydroid 3.
3. Press the Run button.
4. Follow the menu displayed on the screen.

Applications

- Checking balanced parentheses and brackets.
- Simulating a print queue using FIFO (First In, First Out).

Error Handling

The array-based stack and queue report overflow and underflow errors.
